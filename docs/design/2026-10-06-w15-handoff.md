## Decisions already made (do not re-derive)

Stated here in full, not only pointed at.

**Ground and audience (#30):**
- tokenomics' distinct ground is **the session itself**: when to clear,
  compact, or switch the tier of the session the operator is in.
  Dispatch-level routing is superpowers' ground; tokenomics must work
  **without** superpowers (it is usage-heavy).
- The four boundaries are the existing switchpoints (Route, Dispatch,
  Return, Close). Nudges turn each into an action; **no new doctrine**.
- Draft boundary → nudge (from #30; design inside it, don't widen it):
  Close → clear before the next item, re-enter from the playbook;
  Dispatch / decision made → re-score: stay or switch down;
  Return → switch up for this, then back;
  long cycle / context high / cache expired → write state down, then
  compact with a focus, or clear and re-enter.
- **Compaction is safe only when state lives outside context.** Every
  compact nudge is "write it down, then compact".

**The handover offer (owner, 2026-10-03, #30):**
- When a nudge suggests **clearing or compacting**, it **offers a
  ready-made handover**: a re-entry brief drafted from the current state in
  the handoff-spec shape (goal, context pointers, decisions already made,
  what's next).
- The offer produces **a file** the next session opens on (the playbook
  pointer or a handoff spec), not chat text.
- For a **switch-tier** nudge, the same offer doubles as the down-tier
  handoff spec.
- Nudges are **rare and right** (nudge fatigue: a signal that always fires
  stops being read).

**Delivery order (owner, #30):**
1. **Skill text first** (zero install; works in claude.ai too). **This
   handoff covers step 1 only.**
2. Opt-in plugin hooks behind a `userConfig` off-switch (later item).
3. Status-line recipe (later item).

**Harness facts, for the text you write** (second-hand, fetched
2026-10-03; do not build on field names without verifying):
- Plugins and hooks can only **suggest**; they cannot run `/clear`,
  `/compact` or `/model`. Skill text therefore says "suggest", never "do".
- Context % is visible only to the status line, not to hooks or skills.
  Skill-text nudges trigger on **boundaries and observable signs** (a unit
  closed, a decision made, a long run of turns), never on a context
  percentage.

**Superpowers (owner, #30):** a short "composes with" paragraph, plus a
phase mapping in `adapters/` that reads none of superpowers' files. No
live integration (rejected). Upstream contribution only once tokenomics
